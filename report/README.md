# Report Directory

## Suggested Report Structure

1. **Introduction** – goal, why agentic
2. **System Design** – architecture overview
3. **Data Signals** – what the agent extracts from data
4. **Decision Making** – how planning and model selection work
5. **Tool Evaluation** – profiling, modelling, evaluation tools
6. **Reflection & Re-planning** – adaptive mechanisms
7. **Memory & Learning** – what is stored, how it is used
8. **Ethics & Limitations** – responsible AI considerations
9. **Conclusion & Future Work** – summary and next steps
